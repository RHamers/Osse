# CI/CD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two GitHub Actions workflows — one that builds debug + unsigned release APKs on every push to `main`, and one that runs all tests (unit + instrumented) on every PR.

**Architecture:** Both workflows delegate to `build.sh` for the actual build/test logic. Each workflow installs the required toolchain (Java 17, Go 1.26, NDK r23c, gomobile) and sets the env vars that `build.sh` already reads via overridable defaults. Two separate workflow files so each can be triggered independently via `workflow_dispatch`.

**Tech Stack:** GitHub Actions, `actions/setup-java@v4`, `actions/setup-go@v5`, `actions/cache@v4`, `actions/upload-artifact@v4`, `reactivecircus/android-emulator-runner@v2`, Android SDK / NDK (via sdkmanager), Go 1.26, gomobile.

## Global Constraints

- Runs on `ubuntu-latest` (has KVM support for Android emulator)
- Java: temurin 17
- Go: version read from `ytaudio/go.mod` (`go 1.26`) — `actions/setup-go` handles this; do NOT set `GOTOOLCHAIN` env var in CI (that's only needed locally when system Go is older)
- NDK: r23c — version string `23.2.8568313` — matches Unity NDK used in local dev; install via sdkmanager
- gomobile: installed via `go install` after Go + NDK are ready
- `build.sh` reads `ANDROID_NDK_HOME` from env — set it to `$ANDROID_HOME/ndk/23.2.8568313` in every workflow step that calls `build.sh` or gradle
- Release APK is **unsigned** (no signing config in `build.gradle.kts` yet); artifact name `app-release-unsigned.apk`
- Artifact retention: 30 days
- Emulator: API 34, x86_64, pixel profile — matches Robolectric `@Config(sdk = [34])` used throughout tests
- Do NOT add a composite action to deduplicate toolchain steps — YAGNI; two workflows sharing ~25 lines of YAML is fine

### Task 1: Build workflow — build APKs on push to main

**Files:**
- Create: `.github/workflows/build.yml`

**Interfaces:**
- Produces: `app-debug.apk` and `app-release-unsigned.apk` as workflow artifacts

- [ ] **Step 1: Create `.github/workflows/` directory and `build.yml`**

```bash
mkdir -p .github/workflows
```

Then create `.github/workflows/build.yml` with this exact content:

```yaml
name: Build

on:
  push:
    branches: [main]
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Set up Java 17
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'

      - name: Set up Go
        uses: actions/setup-go@v5
        with:
          go-version-file: ytaudio/go.mod

      - name: Cache Go modules
        uses: actions/cache@v4
        with:
          path: ~/go/pkg/mod
          key: ${{ runner.os }}-go-${{ hashFiles('ytaudio/go.sum') }}
          restore-keys: ${{ runner.os }}-go-

      - name: Cache Gradle
        uses: actions/cache@v4
        with:
          path: ~/.gradle/caches
          key: ${{ runner.os }}-gradle-${{ hashFiles('Android/**/*.gradle*', 'Android/**/gradle-wrapper.properties') }}
          restore-keys: ${{ runner.os }}-gradle-

      - name: Install NDK r23c
        run: echo "y" | $ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager "ndk;23.2.8568313"

      - name: Install gomobile
        env:
          ANDROID_NDK_HOME: ${{ env.ANDROID_HOME }}/ndk/23.2.8568313
        run: |
          go install golang.org/x/mobile/cmd/gomobile@latest
          gomobile init

      - name: Build (AAR + debug + release APKs)
        env:
          ANDROID_NDK_HOME: ${{ env.ANDROID_HOME }}/ndk/23.2.8568313
        run: ./build.sh --release

      - name: Upload debug APK
        uses: actions/upload-artifact@v4
        with:
          name: app-debug
          path: Android/app/build/outputs/apk/debug/app-debug.apk
          retention-days: 30

      - name: Upload release APK (unsigned)
        uses: actions/upload-artifact@v4
        with:
          name: app-release-unsigned
          path: Android/app/build/outputs/apk/release/app-release-unsigned.apk
          retention-days: 30
```


Expected: `YAML OK`

## Notes for the implementer

**If the NDK install step fails:** Check which NDK versions are available on the runner with:
```bash
$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager --list | grep "ndk;"
```
Pick the closest available version to r23c and update `23.2.8568313` in both workflow files.

**If gomobile init fails:** It needs `ANDROID_NDK_HOME` set before running. Verify the NDK installed to `$ANDROID_HOME/ndk/23.2.8568313/` before calling `gomobile init`.

**If the release APK artifact upload fails:** The unsigned APK path may differ by AGP version. Check the actual output path with:
```bash
find Android/app/build/outputs/apk/release/ -name "*.apk"
```
Update the path in `build.yml` to match.

**If instrumented tests time out:** The emulator cold-start takes 3–5 minutes. `reactivecircus/android-emulator-runner` handles the wait automatically. Default job timeout on GitHub is 6 hours — no change needed.
